## ⚙️ Sovereign L1 Rust Node Engine

All crates compile under the root workspace [`Cargo.toml`](Cargo.toml):

```bash
# Verify workspace integrity
cargo check --workspace

# Build optimized production binaries
cargo build --release --workspace

# Run DGX Full Node RPC Daemon
cargo run -p dgx-node
```

### Supported JSON-RPC Endpoints:
* `dgx_getBarPassport(barSerial)`: Queries refiner, weight, assay fineness, vault enclave, and Lloyd's insurance policy.
* `dgx_submitDvpOrder(side, pair, quantity, price)`: Submits an atomic Delivery-versus-Payment order.
* `dgx_queryQrngBeacon(round)`: Retrieves verifiable quantum optical vacuum entropy beacon.
* `dgx_getConcessionPassport(concessionId)`: Inspects NI 43-101 reserve metrics and streaming status.
